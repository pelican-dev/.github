# Pelican has moved

Everything that used to live here is now over at [github.com/pelican](https://github.com/pelican), and the only reason this org still exists is so that nobody else can grab the old name and pass themselves off as us.

Most old links should still forward you along on their own, so if you've ended up reading this then one of them probably didn't, and the things you're most likely after are:

- [Panel](https://github.com/pelican/panel)
- [Wings](https://github.com/pelican/wings)
- [Plugins](https://github.com/pelican/plugins)
- [Documentation](https://pelican.dev), which is built from [pelican/docs](https://github.com/pelican/docs)

Nothing new is ever going to be published under this org, so if you come across something that looks like an active pelican-dev repository, it isn't ours and you should be careful with it.

If you're stuck on something, come find us on [Discord](https://discord.com/invite/pelican-panel).
